# 🕵️ Игра в Шпиона (Spyfall Online)

Простая онлайн-версия классической игры «Находка для шпиона» / Spyfall.

## Как играть

1. Один человек создаёт комнату и получает код + ссылку.
2. Друзья переходят по ссылке (или вводят код) и пишут свои имена.
3. Хост нажимает «Начать игру».
4. Всем (кроме шпиона) показывается одна и та же локация.
5. Шпион не знает локацию — он должен её угадать по вопросам.
6. Игроки по очереди задают друг другу вопросы про «место».
7. Через 8 минут (или раньше) раунд заканчивается, все голосуют/обсуждают кто шпион.

## Запуск локально

```bash
cd spy-game
npm install
npm start
```

Открой http://localhost:3000

## Деплой (бесплатно)

### Вариант 1: Render.com
1. Залей репозиторий на GitHub
2. На render.com создай Web Service
3. Build: `npm install`
4. Start: `npm start`
5. Получишь публичную ссылку

### Вариант 2: Railway.app
Аналогично — подключи GitHub, Deploy.

### Вариант 3: Fly.io / Glitch / Replit
Тоже работают отлично.

## Особенности

- Комнаты с 5-символьным кодом
- Ссылка вида `?room=ABCDE`
- До 12 игроков
- 30 локаций на русском
- Таймер 8 минут
- Адаптивный дизайн под телефоны
